# Compatibility status

No Xbox 360 executable format is recognized or loaded. No game or homebrew application has been run. The current CPU prototype executes a tested subset of manually encoded big-endian PowerPC instructions in a flat test buffer. Compatibility with Xbox 360 titles, including the original Xbox 360 version of Grand Theft Auto V, is **not tested**.

The intended future reporting states are: not tested, unsupported, experimental, partial, and confirmed with a reproducible test. File recognition alone must never be reported as successful execution.
