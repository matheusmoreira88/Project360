# Compatibility status

The XEX2 parser recognizes metadata, including import-library names, versions, and import-record addresses. The experimental loader decodes supported import-record fields and maps only unencrypted, uncompressed XEX2 images with validated Xbox PowerPC PE32 sections. A synthetic test program calls twelve kernel shims through guest import thunks, including both `RtlUnicodeStringToInteger` and `RtlIntegerToUnicodeString`, and resumes its caller. `RtlCharToInteger`, `RtlCompareString`, and `RtlNtStatusToDosError` currently have direct-dispatch tests only. `RtlCompareString` rejects non-ASCII case-fold requests explicitly until an Xbox-compatible ANSI upcase table is available. No commercial game or external homebrew application has been run. Other imports, encrypted/compressed images, kernel startup and general title loading remain unsupported. Compatibility with Xbox 360 titles, including the original Xbox 360 version of Grand Theft Auto V, is **not tested**.

The bounded `--run-xex` command can execute up to one million guest instructions from a successfully loaded unencrypted/uncompressed XEX2 image. It stops with an explicit fault diagnostic or an instruction-budget result; neither outcome implies game compatibility. No user-supplied XEX is currently available in the workspace for a run report.

The intended future reporting states are: not tested, unsupported, experimental, partial, and confirmed with a reproducible test. File recognition alone must never be reported as successful execution.
