# Compatibility status

The XEX2 parser recognizes metadata, including image flags, page descriptors, basic-compression blocks, import-library names, versions, and import-record addresses. The experimental loader decodes supported import-record fields and maps unencrypted XEX2 images using no compression or basic data/zero-fill compression with validated Xbox PowerPC PE32 sections. Present page descriptors restrict mapped permissions, and the entry-point page must be executable. A synthetic XEX fixture contains thirteen kernel imports and calls `RtlCompareString` through its thunk in both case-sensitive and ASCII case-fold modes, alongside twelve other imported routines. `RtlCharToInteger` and `RtlNtStatusToDosError` currently have direct-dispatch tests only. `RtlCompareString` rejects non-ASCII case-fold requests explicitly until an Xbox-compatible ANSI upcase table is available. No commercial game or external homebrew application has been run. Other imports, encrypted images, LZX/other compression, kernel startup and general title loading remain unsupported. Compatibility with Xbox 360 titles, including the original Xbox 360 version of Grand Theft Auto V, is **not tested**.

The bounded `--run-xex` command can execute up to one million guest instructions from a successfully loaded supported unencrypted XEX2 image. It stops with an explicit fault diagnostic or an instruction-budget result; neither outcome implies game compatibility. No user-supplied XEX is currently available in the workspace for a run report.

The intended future reporting states are: not tested, unsupported, experimental, partial, and confirmed with a reproducible test. File recognition alone must never be reported as successful execution.
